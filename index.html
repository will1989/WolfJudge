🎯 屠边规则

12人屠边局：好人胜 = 狼人全灭；狼人胜 = 所有神职 或 所有平民 出局（二选一即可）。

👨‍⚖️ 法官唤醒原则

先开局特殊角色 → 功能神 → 信息神 → 特殊狼 → 狼刀 → 女巫 → 后置信息位。

⚠️ 必记结算坑

同守同救 = 死亡（守卫+女巫解药给同一人）。
恶灵骑士：夜间免疫刀/毒；验/毒触发一次反伤后失效；仅白天抗推才死，不能自爆自刀。
石像鬼：普狼全部出局后才能刀人；机械狼：普狼存活不能刀人，学狼后普狼死光解锁双刀。
摄梦：连摄同一人两晚直接死；摄梦人死，当夜所有被摄梦者一同出局。
黑蝙蝠：整局每名玩家仅可被庇护一次；被庇护者免疫夜间技能，首个对其放非狼刀技能者被反弹出局（仅一次），之后不再反弹仍可庇护；狼刀通常不吃反弹。
狼美人：夜里死不带人，仅白天放逐带人，不可连续魅惑。
纯白之女：第一晚只报阵营，第二晚起验狼直接处决。
奇迹商人给到狼人 → 商人当夜直接死亡。
猎人/狼王/学猎人的机械狼：被刀·被投可开枪；被毒杀不能开枪。

🏆 胜负判定

好人屠边胜利：所有狼人出局。狼人屠边胜利：神职/平民全灭。第三方：达成专属条件即胜。
